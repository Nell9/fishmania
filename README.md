# 🎣 КлёвГид (fishmania)

Умный помощник рыбака. Ставите точку на карте, выбираете тип водоёма и снасть — сайт берёт **реальную погоду** (Open-Meteo), рассчитывает температуру воды, показывает какая рыба **реально** здесь ловится, считает шанс клёва из 9 факторов, ранжирует насадки, пишет тактику и рисует анимированные SVG-схемы точек ловли с местом заброса.

Чистая статика без сборки: HTML + CSS + ES-модули. Никаких аккаунтов, ключей и бэкенда.

## Возможности

- **Шанс клёва сейчас + почасовой прогноз на сутки** — сезон, температура воды, давление с трендом, ветер, облачность, фаза Луны, время суток, водоём, насадка.
- **Честная база из 16 видов** (карась, лещ, щука, судак, сом, линь, налим…) с привязкой к типам водоёмов и широте — судака в пруду вам не пообещают.
- **Модель температуры воды** по тепловой инерции водоёма (EMA по погоде за 7 дней, ±2 °C).
- **9 схем точек ловли**: камыш, окно в кувшинках, бровка, коряжник, омут на повороте, перекат, канал, опоры моста, дамба — с дистанцией заброса и профилем дна.
- **Тактика**: место, лучшие часы, прикормка, подача, поправка на погоду.
- Ручной режим условий, если интернета на берегу нет.

## Быстрый старт

| Способ | Команда |
|---|---|
| Windows, в один клик | двойной клик по `Запустить сайт.bat` |
| Node | `npx serve .` |
| Python | `python -m http.server 8080` |
| Без сервера | открыть `klevgid-standalone.html` (однофайловая сборка) |

`index.html` напрямую (file://) не запустится — браузер блокирует ES-модули без HTTP.

## Деплой на сервер (nginx, по IP)

Готовый конфиг: [`deploy/nginx.conf`](deploy/nginx.conf), пошаговая инструкция: [`ai/docs/07-deployment.md`](ai/docs/07-deployment.md).

Защита от ботов и DDoS (без капч): `deploy/nginx-ratelimit.conf` — лимиты на IP и фильтр сканеров, `deploy/fail2ban-jail.local` — бан упорных на файрволе. Применение — в той же инструкции.

```bash
sudo apt install -y nginx git
sudo git clone https://github.com/Nell9/fishmania.git /var/www/fishmania
sudo cp /var/www/fishmania/deploy/nginx.conf /etc/nginx/sites-available/fishmania
sudo ln -s /etc/nginx/sites-available/fishmania /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t && sudo systemctl reload nginx
```

Сайт доступен по `http://<IP-сервера>/`. Нюанс: геолокация в браузере требует HTTPS (см. документацию), клик по карте работает и так.

## Данные

[Open-Meteo](https://open-meteo.com/) (погода, без ключей) · [OpenStreetMap](https://www.openstreetmap.org/) + Leaflet (карта) · Nominatim (название места). Прогноз вероятностный — рыба правила не читала. Соблюдайте нормы вылова вашего региона.
