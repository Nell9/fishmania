# 06 · Дизайн-система

Стиль вдохновлён артефактами Claude: тёплая слоновая кость, терракотовый акцент, серифные заголовки, мягкие карточки, ненавязчивые осмысленные анимации.

## Палитра (CSS-переменные в `:root`)

| Токен | Значение | Роль |
|---|---|---|
| `--bg / --bg-alt` | #faf9f5 / #f3f1e9 | фон страницы / чередование секций |
| `--surface` | #ffffff | карточки |
| `--ink / --ink-2 / --ink-3` | #21201c / #5c594f / #8f8b7c | текст: основной / вторичный / подписи |
| `--line / --line-strong` | #e7e4d8 / #d8d4c4 | бордеры |
| `--accent / --accent-deep` | #d97757 / #bb5d3f | терракота: CTA, выбор, гейдж |
| `--water / --water-deep` | #2e7d9a / #1b5a73 | вода: бейджи шагов, графики, схемы |
| `--good / --warn / --bad` | #4f8a3d / #c08a2d / #b34a3c | семантика (+ их `-soft` фоны) |

## Типографика

- Заголовки: **Lora** (serif, кириллица), `letter-spacing −0.01em`; крупные значения в карточках условий и гейдже — тоже Lora.
- UI/текст: **Inter**. Размеры: body 16px, заголовки clamp() от 1.5 до 3.1rem.

## Геометрия и тени

Радиусы 20/14/9px (`--r-lg/md/sm`). Тени двухслойные мягкие (`--shadow-1/2`). Максимальная ширина контента 1120px.

## Ключевые компоненты

- **.tile** — плитки выбора (водоём, снасть): ховер-подъём, выбранное состояние = терракотовый бордер + галочка `::after`.
- **.chip** — мульти-выбор ориентиров и насадок; selected = инверсия в `--ink`.
- **.cond-card** — карточка условия: лейбл с иконкой, крупное значение, семантический тег.
- **.fish-card** — силуэт SVG + бейдж активности с пульсирующей точкой.
- **.fbar** — бар фактора с анимированным заполнением и подписью-обоснованием.
- **.spot-card** — SVG-схема + мета-чипы + опциональный профиль дна.
- **.snav + .progress-fill** — навигация шагов в шапке с прогресс-линией.

## Анимации

Все на CSS + немного rAF, easing `cubic-bezier(.22,.8,.36,1)`:

| Анимация | Где |
|---|---|
| `.reveal` (fade+up по IntersectionObserver, задержки d1–d4) | секции, хиро |
| `condIn` каскад карточек | условия, рыбы |
| `gaugeSweep` — дуга гейджа через `pathLength=1` + dashoffset | шанс клёва |
| `animateCount` (rAF, cubic ease-out) | проценты, счётчики хиро |
| `barGrow` (scaleY) со стаггером 38мс | почасовой график |
| `drawLine` (dashoffset 1→0) | линии давления и температур |
| `sway / castPulse / flowDash / rippleDrift / fishBob` | SVG-схемы: камыш качается, точка заброса пульсирует, течение бежит |
| `waveShift + fishSwim` | волны и рыба в хиро |

`prefers-reduced-motion: reduce` отключает всё.

## Доступность и адаптив

Семантические кнопки, aria-label на интерактиве и графиках, табличные цифры для значений. Брейкпоинты: 900px (одна колонка, скрытие подписей шагов), 540px, 400px. Печать: скрыты навигация/кнопки — отчёт сохраняется через `window.print()`.
