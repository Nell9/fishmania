# Changelog

## [1.1.0] — 2026-06-11

### Добавлено
- **Выбор точки только на воде**: клик по карте проверяется через OpenStreetMap (Overpass `is_in` + водотоки). Не вода — мастер не пускает дальше; есть «продолжить вручную» и мягкий откат при недоступности Overpass.
- **Авто-определение типа водоёма** по карте (пруд/озеро/река/водохранилище/канал/старица) с предзаполнением шага 2 и авто-отметкой камыша/моста/пляжа.
- **AI-аналитик водоёма (`js/ai-analyst.js`, RAG)**: по реальному рельефу OSM + научной экологии видов оценивает, какая рыба здесь водится, с уверенностью и обоснованием. Провайдеры `local` (работает) и `claude` (заглушка к `/api/ai/analyze`, подключим позже). Уверенность вида управляет потолком честности прогноза клёва.
- **Реальный рельеф точки (300 м)** из OSM: новая схема «вид сверху» с фактической геометрией берега, притоками, камышом, рыболовом на ближнем берегу и реалистичной точкой заброса.
- **Реалистичная дистанция заброса** (`realisticCastDistance`): комфорт снасти, ограниченный размером водоёма (рыбак не кинет на 300 м).
- База рыб расширена до **22 видов** (+уклейка, ёрш, пескарь, верховка, белый амур, толстолобик); добавлены научные поля `ECOLOGY` (кислород, течение, связь с рекой, t нереста, прозрачность, размер) и знаниевый корпус `KNOWLEDGE` + `SOURCES`.
- Документация: `09-ai-analyst.md`, `10-osm-terrain.md`.

### Проверено
- Юнит-тесты OSM (детекция воды, площади, профиль, дистанция), AI-аналитика (изолированный пруд без судака/жереха/сома; крупная река с судаком/лещом/жерехом; честная оговорка при нехватке данных; RAG-промпт), сквозной тест OSM→профиль→AI→клёв→схемы; пересборка standalone без коллизий.

### Восстановление
- После сбоя соединения с папкой рабочее дерево было утеряно и восстановлено из git (до v1.0.x), затем вся работа v1.1.0 пересоздана заново из исходников.

## [1.0.0] — 2026-06-10

Первый релиз.

### Добавлено
- Мастер из 5 шагов + страница прогноза: точка (Leaflet + геолокация + ручные координаты) → тип водоёма (7 типов) с ориентирами места и глубиной → авто-условия → выбор рыбы → снасть и насадки → результат.
- Интеграция Open-Meteo (current + hourly + daily, past_days=7) с конвертацией давления в мм рт. ст.; обратное геокодирование Nominatim; ручной режим условий при недоступности сети.
- Модель температуры воды (EMA по tau водоёма, солнечная поправка, ограничители) + график «вода/воздух, 7 дней».
- База из 16 видов рыб с честной привязкой к водоёмам, сезонам (со сдвигом по широте), температурам, времени суток, насадкам, снастям и ареалам.
- Движок клёва: 9 взвешенных факторов, ограничитель честности по встречаемости вида, вердикты, почасовой прогноз на 24 ч.
- Ранжирование насадок (сезонно-температурные поправки, совместимость со снастью, учёт «что есть у рыбака»).
- Генератор тактики: точка, лучшие часы, прикормка, подача, поправка на погоду, честный совет при слабом прогнозе.
- 9 SVG-схем точек ловли (камыш, кувшинки, бровка, коряжник, омут, перекат, канал, мост, дамба) с анимацией, точкой заброса, дистанцией и профилем дна.
- Анимированные графики: гейдж шанса, бары факторов, почасовая активность с зорьками, давление 48 ч, компас ветра, фаза Луны, силуэты рыб.
- Дизайн-система в стиле артефактов Claude, адаптив, печать отчёта, prefers-reduced-motion.
- Документация ai/docs (концепция, архитектура, данные, API, алгоритмы, дизайн, деплой, roadmap).
- Однофайловая автономная сборка `klevgid-standalone.html` для запуска двойным кликом без сервера.

### Проверено
- Синтаксис всех модулей (node --check), 27 смоук-тестов движка: луна, солнце (±5 мин по 4 городам, полярный день), модель T воды, тренд давления, фильтр реальности видов (судак в пруду скрыт, сом ограничен 14%), скоринг, сортировка насадок (холодная вода → животные), тактика, схемы точек, все SVG-генераторы; сбалансированность тегов HTML; соответствие 49 id между HTML и JS.

### Исправлено
- Знак долготы в фолбэк-расчёте восхода/заката (время сдвигалось на 2×lon/15 ч).
