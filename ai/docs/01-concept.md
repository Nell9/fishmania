# 01 · Концепция

## Идея

КлёвГид отвечает на четыре вопроса рыбака до выезда и на берегу:

1. **Кто здесь реально ловится?** — не абстрактный справочник, а виды, реально обитающие в выбранном типе водоёма на этой широте, отсортированные по активности прямо сейчас.
2. **Когда клюнет?** — почасовой прогноз активности на сутки по реальной метеосводке.
3. **На что ловить?** — ранжирование насадок под вид, температуру воды, сезон и снасть рыбака.
4. **Куда кидать?** — схематичные карты типовых точек (камыш, бровка, коряжник, омут…) с отметкой заброса и дистанцией.

## Принципы

- **Честность.** Если рыбы в водоёме почти нет — прогноз жёстко ограничивается и сайт прямо советует сменить цель. Температура воды всюду помечена как модельная оценка (±2 °C). Прогноз — вероятность, не гарантия.
- **Реальные данные.** Погода, давление, ветер, облачность — живые данные Open-Meteo по координатам точки. Луна и зорьки — астрономический расчёт.
- **Минимум ввода.** Пользователь делает 4–5 кликов: точка → водоём → (условия подтягиваются сами) → рыба → снасть. Всё остальное считает движок.
- **Без сервера и аккаунтов.** Вся логика на клиенте; точка пользователя не покидает браузер (уходит только в метеозапрос).

## Сценарий пользователя

```
Хиро («Начать расчёт»)
 → Шаг 1. Точка: клик по карте / геолокация / координаты
 → Шаг 2. Водоём: пруд·озеро·малая река·крупная река·старица·водохранилище·канал
            + ориентиры на месте (камыш, коряги, бровка…) + глубина
 → Шаг 3. Условия (авто): воздух, вода(модель), давление+тренд, ветер, небо, Луна, зорьки
 → Шаг 4. Рыба: только реально обитающие виды с бейджами активности (или «посоветуйте сами»)
 → Шаг 5. Снасть (поплавок/фидер/спиннинг/живец) + насадки в наличии
 → Прогноз: шанс клёва (гейдж) · разбор факторов · график 24 ч ·
            топ насадок · тактика · 3 схемы точек с местом заброса · сводка
```

## Аудитория

Любители (поплавок, фидер, спиннинг) в России и СНГ. База видов откалибрована под среднюю полосу с поправкой по широте (43°–70° с.ш.).
