# 11 · Дорожная карта и решения (план работ)

Зафиксировано, чтобы не потерять при перезапуске сессии. Исходный код v1.1.0 на диске; ниже — согласованные решения и что делать дальше.

## Принятые решения

- **Бэкенд для ИИ:** Python + FastAPI (чистый SQLite через стандартный `sqlite3`, официальный Anthropic SDK, RAG). Эндпоинты `/api/ai/analyze` (разбор водоёма) и `/api/ai/tactics` (тактика по виду+условиям). Ключ `ANTHROPIC_API_KEY` — в env сервера, в код не попадает. Статический сайт зовёт бэкенд; nginx проксирует `/api/` → FastAPI (uvicorn). Модель: Haiku для разбора видов, при необходимости старше для тактики.
- **База знаний:** SQLite на бэкенде. Таблицы: `species` (вид, латынь, экология), `behavior` (научные повадки по факторам), `baits`, `sources`. RAG достаёт релевантные строки и вкладывает в промпт.
- **Спутниковые карты точек:** реальные тайлы Esri World Imagery, сильный зум на точку + поверх точная геометрия OSM (берег, камыш, притоки) и кликабельные точки ловли. Детерминированно, повторяет реальный рельеф. Перспектива: top-down с ориентацией «берег пользователя снизу → вода вверх».
