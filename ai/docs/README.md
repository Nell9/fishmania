# КлёвГид — документация проекта

## Быстрый старт

Проект — чистая статика, сборка не нужна.

**Windows:** двойной клик по `Запустить сайт.bat` — поднимет локальный сервер (PowerShell, без зависимостей) на `http://localhost:8080` и откроет браузер.

Либо любой статический сервер:

```bash
npx serve .          # или
python -m http.server 8080
```

Открыть `http://localhost:8080`. Для работы карты, шрифтов и погоды нужен интернет; без него сайт переключается в ручной режим ввода условий.

> Основная версия через `file://` не запустится: ES-модули требуют HTTP. Для быстрого просмотра двойным кликом есть **`klevgid-standalone.html`** — автособранная однофайловая копия (CSS+JS инлайн, без модулей). Источник истины — модульная версия; standalone пересобирается после правок (см. 02-architecture.md).
