# 03 · Модель данных (`js/fishdb.js`)

Все справочники — обычные JS-объекты, ключ = id. Числовые веса в диапазоне 0..1.

## WATERS — типы водоёмов

| Поле | Смысл |
|---|---|
| `tau` | тепловая инерция воды, сутки (для модели T воды): пруд 2.5 … водохранилище 7 |
| `sun` | множитель солнечного прогрева (мелкие водоёмы >1) |
| `flow` | течение: 0 нет, 1 слабое, 2 заметное (влияет на T и прикормку) |

Типы: `pond, lake, river_small, river_big, oxbow (старица), reservoir, canal`.

## FISHES — 16 видов

| Поле | Смысл |
|---|---|
| `waters` | реальная встречаемость по типам водоёмов 0..1 — главный фильтр честности |
| `months[12]` | сезонная активность янв..дек для средней полосы (сдвигается по широте) |
| `temp[4]` | трапеция комфорта T воды: [мин, опт-мин, опт-макс, макс] |
| `times` | активность по периодам: dawn/day/dusk/night |
| `depth` | предпочтение глубины места: shallow/mid/deep |
| `baits` | привлекательность насадок 0..1 (база до сезонных поправок) |
| `tackle` | пригодность снастей 0..1 |
| `lat[2]` | границы ареала по широте, плавный спад за пределами ±3° |
| `habitat` | теги мест: reeds, lilies, snags, dropoff, flat, bridge → выбор схем |
| `shape, hue` | силуэт и цвет для SVG-карточки |

Виды: карась, карп/сазан, плотва, лещ, окунь, щука, судак, сом, язь, голавль, линь, краснопёрка, густера, налим, жерех, ротан.

### Принципы калибровки

- `waters` отражает реальность, а не «можно встретить»: судак в пруду = 0.02, ротан в крупной реке = 0.
- `months` — открытая вода; зимний пик налима намеренно сохранён (ноябрь–январь = его сезон).
- При `waters × latPresence < 0.15` движок ограничивает итоговый шанс 14% и советует сменить цель.

## BAITS — 15 насадок/приманок

`cat`: `animal` (червь, опарыш, мотыль…), `plant` (кукуруза, перловка, тесто…), `live` (живец), `artificial` (вертушка, колебалка, воблер, джиг). `tackle[]` — совместимые снасти. Сезонные поправки к категориям — в engine (см. 05).

## TACKLE, FEATURES, DEPTHS

Снасти: float, feeder, spinning, livebait. Ориентиры места (отмечает рыбак): reeds, lilies, snags, dropoff, flat, bridge — усиливают соответствующие схемы точек и тактику. Глубина места: shallow (<1.5 м), mid (1.5–3), deep (>3).

## Как добавить вид

1. Добавить объект в `FISHES` по образцу (все поля обязательны).
2. Выбрать `shape` из существующих силуэтов (`charts.js: FISH_SHAPES`) или добавить новый.
3. Проверить: вид должен появляться только в «своих» водоёмах и широтах.
