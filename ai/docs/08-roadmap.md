# 08 · Roadmap

## Ближайшее (v1.x)

- [ ] Тёмная тема (`prefers-color-scheme` + переключатель).
- [ ] Прогноз на выбранную дату/время выезда, а не только «сейчас» (API уже отдаёт 2 дня, нужен UI выбора).
- [ ] Сохранение «моих мест» (несколько точек в localStorage, быстрый выбор).
- [ ] Шаринг отчёта ссылкой (состояние в URL-параметрах).
- [ ] PWA: манифест + service worker, офлайн-кэш оболочки.

## Среднесрочно (v2)

- [ ] Зимний режим: лёд, мормышка/жерлицы, зимняя база активности.
- [ ] Дневник уловов: факт ловли против прогноза → локальная статистика точности.
- [ ] Больше видов (стерлядь?, хариус, форель — горные реки) и региональных профилей (юг, Сибирь, Карелия).
- [ ] Учёт мутности/уровня воды (после дождей) по осадкам за неделю — данные уже запрашиваются.
- [ ] Глубинные карты реальных водоёмов (открытые данные) вместо только типовых схем.

## Дальняя перспектива

- [ ] Бэкенд-прокси для метео (кэш на сервере, экономия лимитов) — модули движка переносимы как есть.
- [ ] Калибровка весов модели на собранной статистике уловов (см. дневник).
- [ ] Сообщество: подтверждённые точки, отчёты с воды.

## Принципы при развитии

Не ломать честность (фильтр реальности видов — неприкосновенен), не добавлять аккаунты без необходимости, держать деплой «скопировал — работает».
